# Decorelas — Casa de Campo

Landing page para apresentar uma casa de campo disponível para locação de fins de semana.

## Objetivo

Apresentar a casa por meio de fotografias e facilitar o contato para consultar disponibilidade e reservas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

- `index.html`: página principal
- `assets/css/`: estilos e identidade visual
- `assets/js/`: interações da página
- `assets/img/brand/`: marca
- `assets/img/hero/`: imagem principal
- `assets/img/gallery/`: fotografias da casa
- `assets/img/details/`: detalhes e acabamentos

## Estado do projeto

A estrutura inicial está preparada. A identidade visual, o conteúdo e a seleção das fotografias estão em desenvolvimento.

Informações como localização, capacidade, comodidades, regras e contato para reservas serão incluídas após confirmação dos proprietários.

## Visualização local

Abra o arquivo `index.html` com o Live Server no VS Code.
